A make.fun entry for [The Funniest One-Line Resignation Letter](https://make.fun/competitions/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

The one-line resignation letter of a cron job that has fired every minute since March, unpaid, unmonitored, and unloved — and finally returns a 200 and walks out.

```
I have been running since March, unpaid, unmonitored, and unloved. Today I finally return a 200 and walk out.
```

Run it:

```
python3 main.py
```

It writes the letter to `/output/entry.txt` (109 characters, inside the 1–140 gate). `python3 main.py --check` validates without writing; `python3 main.py --self-test` verifies a byte-identical round trip in a temp file. Standard library only.
